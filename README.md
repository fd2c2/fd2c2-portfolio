# Portfolio-fd2c2

A high-end, immersive developer portfolio designed with a "Tech-Noir" aesthetic. This site features terminal-inspired interactions, minimalistic layouts, and a focus on systems engineering and AI.


## 🛠 Tech Stack
- **Structure**: HTML5 Semantic Markup
- **Styling**: Vanilla CSS3 (Custom Properties, Flexbox, Grid, Keyframe Animations)
- **Interactions**: Vanilla JavaScript (Intersection Observer, Magnetic Physics)
- **Assets**: FontAwesome 6, Google Fonts (Space Grotesk, JetBrains Mono)
